## Findings

### Should fix
1. **Dataroom branding colour regression.** The old header coloured the title and brand link with
   `var(--viewer-primary)` (from `scopeData.brand_primary_color`, `DataroomViewer.jsx:747`). The new header
   hardcodes `text-gray-900` / `text-gray-700`, so dataroom white-labelling no longer affects the topbar.
   **Fix:** use `var(--viewer-primary)` (falls back to `#111827`) for title and brand name, or explicitly accept
   the change in the PR.
2. **No tests for the new component.** Only two lines changed in an existing test. Nothing covers owner chip,
   Q&A button disabled without `hasViewSession`, thread-count badge, `qnaText` override, or title omission.
   **Fix:** add `src/tests/components/viewer/DocumentViewerHeader.test.jsx` and register it in
   `frontend/vitest.whitelist.json`, otherwise CI skips it.

### Minor
3. **Unused prop.** `isQnaOpen` is passed by both viewers but never read by the header (could drive
   `aria-pressed`, or remove it).
4. **Mobile attribution/owner hidden.** "Powered by Coneshare" is `hidden md:flex`; owner chip `hidden sm:flex`;
   Q&A label icon-only below `sm`. Previously "Powered by" showed at all sizes. Confirm intended.
5. **Fixed-height children not verified.** Body is now `flex-1 min-h-0 overflow-hidden` under a 56px header. No
   `h-screen`/`100vh` found in the five viewer components, so clipping is unlikely; visually check PDF, video,
   spreadsheet and Markdown on narrow viewports. In fullscreen (`viewerRef`) the white header now sits above
   the `zinc-900` video background.
6. **Dead/old styling.** `dark:text-gray-100 dark:hover:text-gray-300` on the Coneshare link is ineffective on
   the white header; `alt={`${brandName} logo`}` is English-only (pre-existing).
7. **PR hygiene.** AGENTS.md requires UI screenshots/GIFs for frontend changes; none in the PR description.
